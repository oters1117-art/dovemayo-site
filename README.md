# dovemayo

둘기마요의 링크 홈페이지와 이모지 스네이크 게임. https://dovemayo.com/

## 로컬 실행

`python -m http.server 4173 --directory dist`

http://localhost:4173 에서 확인합니다. 별도 설치나 서버 데이터베이스가 필요 없는 정적 사이트입니다.

- 홈페이지: `dist/index.html`
- 스타일: `dist/style.css` (수정 후 `node scripts/sync-style.mjs` 실행)
- 게임 화면/입력: `dist/snake.mjs`
- 게임 규칙: `dist/snake-engine.mjs`
- 음악 발판: `dist/music-pads.mjs`
- 효과음: `dist/foley.mjs`

CSS와 작은 제목 폰트는 첫 화면 지연을 줄이도록 HTML에 포함합니다. 게임 모듈은 modulepreload로 미리 요청합니다. 원본 PNG와 무손실 WebP를 함께 보관합니다. 음악은 재생할 때 불러옵니다.

## 검증

`node --test tests/snake.test.mjs tests/music-pads.test.mjs tests/touch-steering.test.mjs`

## 배포 및 권리

현재 사이트는 Cloudflare Workers Static Assets에서 호스팅합니다(2026-10-13 이전 완료). 프로덕션은 https://dovemayo.com/, 보조 주소는 https://dovemayo-site.oters.workers.dev/ 입니다. ChatGPT/Codex 구독과 별도로 운영됩니다.

배포: `npx wrangler deploy --config wrangler.jsonc` (Cloudflare 로그인 필요). `dist/`만 업로드하며 별도 빌드나 서버 DB는 없습니다. 이 GitHub 저장소에 올리는 것만으로 자동 배포되지는 않습니다. `.openai/hosting.json`은 이전 Sites 배포의 기록이며, 현재 프로덕션 업데이트에는 사용하지 않습니다.

공개 저장소는 열람을 위한 것으로, 작품·폰트·음악 등의 재사용 허가를 의미하지 않습니다. 외부 이모지와 효과음의 출처 및 라이선스는 `dist/emoji/LICENSE.txt`, `dist/audio/CREDITS.txt`를 확인하세요.


## 보스 확장 로컬 테스트

`python scripts/preview-server.py --port 4174`

- 테스트: http://127.0.0.1:4174/
- 방향키 또는 컨트롤러 카드로 시작. 게임 중 `1`: 토마토, `2`: 문어심장, `3`: 뇌, `4`: 왕/성, `q`: 특수 음식, `w`: 적, `0`: 케이크.
- 테스트 키는 localhost / 127.0.0.1에서만 동작합니다.
- 보스 순서는 매 판 무작위이며 60 / 150 / 240 / 330초(1:00 / 2:30 / 4:00 / 5:30)에 등장합니다.
- 뇌는 첫 칼 공격에 알이 되고, 12초 안에 다시 칼로 공격하지 않으면 돌아옵니다.
- 문어심장은 당구공 3회 명중으로, 다른 보스와 왕의 손은 칼로, 성은 다이너마이트로 처치합니다. 네 보스와 성을 마무리하면 케이크가 등장합니다.
- 다이너마이트는 몸으로 운반할 수 있으며 적·폭탄·투사체에 부착됩니다. 카드와 글자에는 부착되지 않습니다. 폭발 전 벗어나세요.
- `node --test tests/*.test.mjs`, `node tests/boss-long-run.mjs`, `python tests/analytics_test.py`

### 개인 통계

http://127.0.0.1:4174/admin 주소로 바로 열립니다. 로그인은 없으며 홈페이지에 관리 링크를 표시하지 않습니다. 방문·플레이 기록은 `.sites-runtime/analytics.sqlite3`에 저장되고 Git에는 포함되지 않습니다.

사용자 요청대로 주소를 아는 사람은 관리 화면과 집계 API를 열 수 있습니다. 검색 제외 태그를 적용했으며, 로컬 서버는 127.0.0.1에서만 받습니다.

**현재는 로컬 테스트 기록만 집계합니다.** 기존 정적 Sites 배포에는 Python 서버가 포함되지 않습니다. 실제 사이트 통계 적용 때는 관리 API와 영속 데이터베이스를 배포 환경에 연결해야 합니다. 게임 파일만 공개 배포해서는 통계가 수집되지 않습니다.

방문자는 브라우저 쿠키 단위로 중복 제거되며, 시크릿 창이나 쿠키 삭제는 새 방문자입니다. 게임 중 15초 간격으로 생존 시간과 화면 활성 시간을 따로 기록합니다. 클라이언트 통계는 공인 랭킹이나 부정행위 검증용이 아닙니다.

보스 조정: 클래식 MIDI 음표와 화음 구름 / 유도 레이저 / 단일 전역 블랙홀, 문어심장 공중 칼 무효 / 포물선 망치 / 지형에 계속 튕기는 당구공, 실제 접촉하는 왕의 양손 / 설치 후 점화되는 다이너마이트.

통계 화면은 플레이어 수, 플레이어당 누적 평균 활성 플레이 시간, 플레이어별 최고 점수·최고 생존 시간 TOP 20을 표시합니다. 보스 공격은 매번 무작위입니다. 토마토는 원형 탄막·기관총(0.14초)·샷건(퍼짐 약 69°)·느슨한 단발(조준 ±0.25rad, 0.38~0.6초 간격) 중 직전과 다른 패턴을 고르며, 문어심장과 뇌는 같은 공격이 연속될 수 있습니다. 문어심장의 프레스 점프는 플레이어가 240px 넘게 떨어져 있을 때만 나오며, 착지 시 바닥 프레스로 공격합니다. 망치를 뿌리며 물러나는 후퇴 점프는 착지 충격파와 바닥 효과가 없으며, 착지한 몸에 닿으면 평소처럼 죽습니다.

나자르 부적(자기 몸 관통 가능), 가지 콤보(시간 정지 10초), 맥주 콤보(피아 구분 사라짐 10초), 케이크 클리어는 게임마다 처음 한 번만 `둘기마요` 오른쪽에 붉은 글씨로 효과만 표시됩니다. 케이크를 처음 먹으면 이어서 `[Space bar]로 블루베리 발사`가 표시됩니다.

벽·카드·글자에 부딪혀도 죽지 않고 튕겨 나갑니다. 비스듬히 부딪히면 반사각으로 튕기고, 정면에 가까우면 표면을 따라 미끄러지며, 방향은 최대 90°까지만 꺾입니다. 가지 디버프는 4초, 독 웅덩이 감속은 6초입니다. 성은 지형지물이라 부딪히면 벽처럼 튕기고 죽지 않습니다.

일반 적은 생성될 때마다 성격(속도 ±12%, 교전 거리 0.8~1.25배, 휴식 시간 0.75~1.25배, 궤도 반경, 35% 확률의 좌우 지그재그 접근)이 조금씩 달라집니다. 카우보이는 던진 뒤 플레이어보다 느리게(약 88~112px/s) 2.4~3.4초간 물러납니다.

케이크를 먹은 뒤에는 Space로 블루베리를 한 발씩 쏠 수 있습니다(누르고 있으면 연사). 간격은 케이크 1개 0.7초, 2개 0.55초, 3개 0.4초, 4개 이상 0.25초이며 블루베리 버프(0.14초)보다 항상 느립니다. 피날레 연출 중에는 쏠 수 없습니다. 죽은 뒤 버튼에는 `enter / esc`가 표시됩니다.

조회수는 페이지 로드별로 집계하며 오늘(KST)·누적 조회수와 유입 도메인을 표시합니다. 기존 방문 세션과 구분하여 이번 버전부터 pageviews 테이블에 기록합니다. 직접 방문 또는 리퍼러 미전달은 알 수 없음으로 표시하며, 경로·검색어·URL 쿼리는 저장하지 않습니다.

케이크는 8초간 내려오며 적을 추가 소환합니다. 획득 시 3.8초간 슬로모션과 순차 별 파티클 후 정상 진행합니다. 케이크 등장 시 Still Alive(`dist/music/still-alive.mp3`)와 사용자 제공 종소리를 재생합니다.
